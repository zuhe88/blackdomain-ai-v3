電子加速器

戰神賽特 1、戰神賽特 2、古神巴風特、虎小妹、赤三國支援動畫加速與本金控管。這五款也可在遊戲內開啟免遊劇透。

已安裝？一鍵更新到 0.7.12

Windows 版 Chrome／Edge 可用更新工具，把新版寫入原本載入的資料夾。

下載一鍵更新工具 0.7.12

執行更新工具後，到擴充功能頁按「重新載入」，再重新整理遊戲。

第一次安裝

下載擴充功能 ZIP 0.7.12
  1. 下載 ZIP 並解壓，保留內含 manifest.json 的資料夾。
  2. 在桌面 Chrome 開啟 chrome://extensions，Edge 使用 edge://extensions。
  3. 開啟「開發人員模式」，點「載入未封裝項目」，選擇剛解壓的資料夾。
  4. 用同一個瀏覽器登入黑域 AI，再開啟或重新整理遊戲。

動畫加速

進入遊戲後，等面板顯示「加速已就緒」即可選擇倍率。「1×」會恢復原速。各款加速的動畫會依遊戲可偵測的元件而異。

免遊劇透

遊戲回傳完整免遊結果時，面板會提早顯示總分。分段回傳時，如果遊戲有提供累計分數，就會顯示「累計中」。正式結算後會記錄最近五次結果。

本金控管

戰神賽特 1、戰神賽特 2、古神巴風特、虎小妹、赤三國已納入相容性偵測。面板可儲存門檻時，代表已偵測到控管介面。各款真桌停止效果仍待驗證。

開啟「本金控管」，填寫低於或高於多少停止並儲存，留空可略過該門檻。門檻套用於遊戲原生自動轉。
