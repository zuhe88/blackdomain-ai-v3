電子加速器

在遊戲內設定本金停止門檻。戰神賽特 2 指定頁面還提供動畫加速與免遊紀錄。

下載擴充功能 0.7.2

安裝方式

  1. 下載 ZIP 並解壓，保留內含 manifest.json 的資料夾。
  2. 在桌面 Chrome 開啟 chrome://extensions，Edge 使用 edge://extensions。
  3. 開啟「開發人員模式」，點「載入未封裝項目」，選擇剛解壓的資料夾。
  4. 用同一個瀏覽器登入黑域 AI，再開啟或重新整理遊戲。

本金控管

戰神賽特 1、戰神賽特 2、古神巴風特、虎小妹、赤三國已納入相容性偵測。面板可儲存門檻時，代表已偵測到控管介面。各款真桌停止效果仍待驗證。

開啟「本金控管」，填寫低於或高於多少停止並儲存，留空可略過該門檻。門檻套用於遊戲原生自動轉。
