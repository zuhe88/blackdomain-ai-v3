# 黑域 AI 電子加速器 0.6.6 測試版

## 安裝

1. 解壓縮 ZIP。載入的是解壓後直接含有 `manifest.json` 的資料夾，安裝後請保留這個資料夾。
2. Chrome 開啟 `chrome://extensions`，Edge 開啟 `edge://extensions`。打開「開發人員模式」，按「載入未封裝項目」，選擇上述資料夾。
3. 從工具列的擴充功能選單打開「黑域 AI 電子加速器」，按「開啟動畫示範」即可試用 1×、10×、20×、50×、恢復原速和最近五次免遊紀錄。示範得分是測試資料。
4. 要在戰神賽特 2 測試，先以同一個瀏覽器設定檔登入黑域會員入口，再從 3A 開啟遊戲。看到左上角顯示「加速已就緒」後可以切換倍率。「1×」會還原原始速度。

## 此版本的範圍

- 3A 戰神賽特 2 可調整符號掉出、落下、補位、消除、得分跳字、餘額數字過場、倍數球及部分連消與大獎特效。倍率套用於這些動畫的可調時間，整局耗時仍包含平台回應及其他動畫。
- 最近五次免遊直接取自賽特 2 的免遊結算畫面，包含自然觸發及購買免遊。重新載入分頁後會重新開始記錄。
- Windows Edge 已用隔離設定檔驗證安裝與模擬動畫。Chrome 已驗證 0.1.0 安裝。0.5.7 的 3A 真桌完整轉動與結算尚待驗證。

## 本金控管

在賽特 2 面板開啟「本金控管」，設定指定轉數或持續自動轉，以及最低餘額。按「儲存設定」後，仍從遊戲原本的自動轉按鈕開始。每次自動轉前會依遊戲的下注額計算扣款後餘額，低於門檻就停止。更換遊戲分頁後需重新設定。0.6.6 的本金控管已做離線流程測試，真桌尚待確認。
