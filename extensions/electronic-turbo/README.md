# 黑域 AI 電子加速器 0.1.0 測試版

## 安裝

1. 解壓縮 ZIP。載入的是內含 `manifest.json` 的 `electronic-turbo` 資料夾，安裝後請保留這個資料夾。
2. Chrome 開啟 `chrome://extensions`，Edge 開啟 `edge://extensions`。打開「開發人員模式」，按「載入未封裝項目」，選擇上述資料夾。
3. 從工具列的擴充功能選單打開「黑域 AI 電子加速器」，按「開啟動畫示範」即可試用 1×–10×、恢復原速和最近五次免遊紀錄。示範得分是測試資料。
4. 要在戰神賽特 2 測試，先以同一個瀏覽器設定檔登入黑域會員入口，再從 3A 開啟遊戲。看到左上角顯示「得分看板動畫就緒」後可以切換倍率。「恢復 1×」會還原原始速度。

## 此版本的範圍

- 3A 戰神賽特 2 的介接範圍是得分看板的 Spine 動畫。轉軸、音效、開獎、派彩和下注使用遊戲原本流程。
- 最近五次免遊由同一分頁的黑域 ATG 轉發器提供自然觸發的免遊得分。重新載入分頁會重新開始記錄；沒有轉發資料時畫面顯示等候結算。
- Windows Edge 已用隔離測試設定檔驗證。3A 真桌完整轉動與結算、Chrome 實際安裝及 macOS 尚待驗證。
