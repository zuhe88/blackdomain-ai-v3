# 黑域 AI 電子加速器 0.7.8 測試版

## 安裝

1. 解壓縮 ZIP。載入的是解壓後直接含有 `manifest.json` 的資料夾，安裝後請保留這個資料夾。
2. Chrome 開啟 `chrome://extensions`，Edge 開啟 `edge://extensions`。打開「開發人員模式」，按「載入未封裝項目」，選擇上述資料夾。
3. 從工具列的擴充功能選單打開「黑域 AI 電子加速器」，按「開啟動畫示範」即可試用 1×、10×、20×、50×、恢復原速和最近五次免遊紀錄。示範得分是測試資料。
4. 要在支援的遊戲上使用，先以同一個瀏覽器設定檔登入黑域會員入口，再從 3A 開啟遊戲。看到面板顯示「加速已就緒」後可以切換倍率。「1×」會還原原始速度。

## 此版本的範圍

- 戰神賽特 1、古神巴風特、虎小妹、赤三國已開放加速選項。加速套用於可偵測的遊戲動畫，實際支援的動畫依各款而異。

- 3A 戰神賽特 2 可調整符號掉出、落下、補位、消除、得分跳字、餘額數字過場、倍數球及部分連消與大獎特效。倍率套用於這些動畫的可調時間，整局耗時仍包含平台回應及其他動畫。
- 五款支援遊戲均會偵測免遊資料。有完整結果時顯示待結算總分，有明確的分段累計分數時顯示累計中，正式結算後保留最近五次紀錄。重新載入分頁後會重新開始記錄。
- Windows Edge 已用隔離設定檔驗證安裝與模擬動畫。Chrome 已驗證 0.1.0 安裝。0.5.7 的 3A 真桌完整轉動與結算尚待驗證。

## 本金控管

戰神賽特 1、戰神賽特 2、古神巴風特、虎小妹、赤三國已納入相容性偵測。面板會在偵測到遊戲提供相容的餘額與停止介面後開放設定。

在賽特 2 面板開啟「本金控管」後可設定低於及高於的停止門檻。空白可停用個別門檻。遊戲原生自動轉執行時，以扣除下一注後的試算餘額檢查下限，以目前餘額檢查上限。真桌尚待確認。
